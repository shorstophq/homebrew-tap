# shorstophq/homebrew-tap

Homebrew tap for [ShorStop](https://github.com/shorstophq/shorstop), the post-quantum
cryptography scanner and CycloneDX CBOM generator.

```sh
brew install --cask shorstophq/tap/shorstop
```

Installing by the full name trusts only this cask (Homebrew tap trust); there's no need to
trust the whole tap. Works on macOS and Linux.

`Casks/shorstop.rb` is generated by GoReleaser on each ShorStop release. Don't edit it by
hand: changes belong in ShorStop's
[`.goreleaser.yaml`](https://github.com/shorstophq/shorstop/blob/main/.goreleaser.yaml).
